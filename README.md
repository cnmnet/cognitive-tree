# 认知晶体树 · 认知增强引擎

[![Python](https://img.shields.io/badge/Python-3.10+-blue.svg)](https://python.org)

认知晶体树是一个**认知增强引擎**，通过多角色辩论、沉思式反思和八道防线，帮助用户做出更高质量的决策。

## ✨ 核心功能

- **多角色辩论**：激进者、保守者、结构主义者等多方博弈，输出结构化报告
- **PR 审计**：输入 GitHub PR diff → 三方辩论 → 输出代码风险报告
- **沉思式反思**：正念、空性、非二元性、无边关怀四维度深度思考
- **八道防线**：知识贫瘠、偏见膨胀、信息枯竭、思维固化等质量保障
- **Gödel 自我进化**：AI 自主改进 Prompt，越用越聪明
- **Skill 市场**：创作者发布 Skill，获得 Star 即获得分成权重

## 🚀 快速开始

```bash
# 安装依赖
pip install -r requirements.txt

# 启动 Web 服务
python crystal_tree_all_in_one_day.py --web

# 启动 GUI
python crystal_tree_all_in_one_day.py --gui
