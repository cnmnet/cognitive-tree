## 一、埋点位置总览

| 编号 | 位置 | 触发时机 | 数据用途 |
|------|------|----------|----------|
| M01 | **入口**：前端输入框 | 用户点击发送/按回车 | 记录用户发起请求的原始时间 |
| M02 | **出口**：后端输出完成 | 系统完成答案生成 | 记录系统完成响应的原始时间 |

**当前状态**：仅标注位置，不实施具体埋点代码。待系统稳定后统一实施。


## 二、宏观埋点描述

### M01：入口埋点

| 属性 | 描述 |
|------|------|
| **位置** | 用户提交输入时（GUI 输入框 / Web 输入框） |
| **触发函数** | `_do_chat()` / `_do_crystal()` / `_do_deep_reasoning()` |
| **记录内容** | 用户提交时间戳、会话ID、输入内容摘要 |
| **记录格式** | `{ "event": "input_submit", "timestamp": "...", "session_id": "...", "input_preview": "..." }` |

### M02：出口埋点

| 属性 | 描述 |
|------|------|
| **位置** | 系统完成输出时（GUI 日志区域 / Web 响应返回） |
| **触发函数** | `_chat_done()` / API 响应返回前 |
| **记录内容** | 输出完成时间戳、输出长度、引用的晶体ID列表 |
| **记录格式** | `{ "event": "output_complete", "timestamp": "...", "session_id": "...", "output_length": 1234, "crystals_referenced": ["C001", "C003"] }` |

### M03：关键转折点埋点

| 属性 | 描述 |
|------|------|
| **位置** | 用户输入特定短语时（“我的理解是”、“我觉得核心是”、“换句话说”） |
| **触发函数** | `_do_chat()` 中的内容识别 |
| **记录内容** | 用户复述时间戳、复述内容摘要 |
| **记录格式** | `{ "event": "user_understands", "timestamp": "...", "session_id": "...", "understand_preview": "..." }` |
