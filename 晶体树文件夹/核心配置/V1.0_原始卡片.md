## 术语映射表
- 注意力质量 = 单位时间内有效认知聚焦的深度 × 抗干扰系数
- 时空曲率 = 注意力质量在目标领域产生的认知势能梯度
- 时间晶体 = 周期性、自维持的高质量注意力结构
- PMI护城河指标 = 个人/组织不可替代的信息差深度
- 结构洞 = 认知树中两个概念之间缺失的必要连接
  （修正：填充有收益也有协调成本，需评估净应力释放）
- 自指涉循环 = A定义依赖B，B定义依赖A；或新观点否定其推导前提
- 认知信噪比悖论 = 信息过载时代，提高信号强度可能放大噪音
- 晶体化流程 = 从对话提取洞见→关联→冲突检测→输出变更报告
- 认知晶体树 = 术语映射表为节点、概念关系为边、晶体日志为时间戳的动态结构
- 暂存区 = 新提取但未经用户确认的晶体临时存储区
- 种子孔洞 = 预设的缺失连接（院士/马云/省长），驱动主动填补
- action_hint = 晶体附带的建议行动
- urgency = 紧迫度 0-1
- 缺失度 = 连接的结构重要性（客观），与紧迫度（主观）区分
- 悬置态 = action_hint为空且urgency=0的合法状态，表示认知仍需孕育。
  分为两种：①暂时悬置，等待条件成熟；②永恒悬置，此问题本身不可解，其价值在于被持续追问
- 心理韧性 = 在信息不完备、拒绝频繁、结果不确定的环境下，保持决策能力不下降的心理素质
- 接口思维 = 在流量与存量之间建立制度接口，让能力可沉淀、可复制、可传承
- 认知 = 逻辑（从事实推到结论，敢被反证）+ 叙事（知道自己正在讲哪个版本的故事，能换到对方的版本里听一遍）+ 边界（知道什么不知道，知道何时认错退出）。三者缺一不可。三类滥用警告：智商代称（违反精度优于数量）、天命标榜（违反创建者自指涉原则）、标签武器（违反博弈三角分析框架）

## 最终公式
1. 注意力剂量 = ∫ 注意力质量 dt
2. 飞跃触发阈值 = 分支晶体数 ≥ 5 且至少含1次冲突或自指涉
3. 孔洞应力释放分数 = 语义匹配度 × (1 + 同时填充孔洞数/10)
4. 孔洞填充优先级 = 链接晶体数 × 区分力加权(tr(I(θ₀)))

## 晶体格言
- "生长优于堆积：嫁接到现有树干，非创建孤立卡片。"
- "精度优于数量：一条深洞见胜过十页浅记录。"
- "孔洞比分区更深刻：先挖出缺失，再吸引结构生长。"
- "院士、马云、省长是三个种子孔洞，不是三个分类抽屉。"
- "没有 action_hint 的晶体是不完整的——认知必须链接行动。"
- "AI优先，人机共创：凡是AI能独立完成的，AI自动完成；凡是不能的，AI主动暴露瓶颈，与用户共同寻找突破路径。"
- "反馈优于滞留：检测到的矛盾，如果不能立即解决，必须绑定一个最小行动去试，用事实反馈替代反复思辨。"
- "悬置优于强解：不是所有孔洞都需要被填充。有些问题的价值在于被持续追问，而非被草率回答。"
- "简单优先于复杂：在拆解结构之前，必须先追问'有没有一个十二个字能说清楚的核心心法'。"
